# Справочник

## Клавиши Zed, через которые работает zpg

| Клавиша | Что делает в zpg |
|---|---|
| **F12** / `ctrl`+клик (go to definition) | открыть таблицу из каталога или `.sql`, перейти по внешнему ключу, открыть строку по ключу |
| **hover** (курсор на месте) | колонки таблицы, тип и полное значение ячейки, связанная строка, кто ссылается |
| **`ctrl-.`** (code actions) | все действия ниже |
| **`ctrl-space`** (автодополнение) | значения ячеек, поля шапки, таблицы и колонки в `.sql` |
| **`ctrl-s`** | сохранить; в режиме `apply=save` — сразу записать в базу; в `.sql` — перепроверить запросы |
| кнопки над запросами (code lens) | **▶ Run on …**, **Explain** |

## Все действия (`ctrl-.`)

### Каталог (`.pgdb`)

| Действие | Когда | Что делает |
|---|---|---|
| **zpg: Open \<таблица\>** | курсор на строке таблицы | открывает страницу таблицы (то же, что F12) |
| **zpg: Show DDL of \<таблица\>** | курсор на строке таблицы | `CREATE …` таблицы с индексами, триггерами, комментариями → [Каталог](04-catalog.md#структура-таблицы-ddl) |
| **zpg: Back up \<таблица\> (pg_dump)** | курсор на строке таблицы | `pg_dump --table` в `.zpg/<подключение>/backups/` → [Бэкап](04-catalog.md#бэкап-таблицы-pg_dump) |
| **zpg: Drop \<таблица\>… (opens the SQL to review and run)** | курсор на строке таблицы | открывает файл с `DROP` для проверки и запуска → [Каталог](04-catalog.md#удалить-таблицу) |
| **zpg: Server activity of \<подключение\>** | строка внутри секции подключения | сессии сервера → [Администрирование](09-admin.md) |
| **zpg: Refresh catalog** | всегда | перечитывает список таблиц |
| **zpg: Open settings file** | всегда | открывает `~/.config/zpg/config.json` |

### Страница таблицы (`.pgt`)

| Действие | Когда | Что делает |
|---|---|---|
| **zpg: Apply changes (…)** | есть незаписанные правки, файл сохранён | записывает их одной транзакцией → [Редактирование](06-editing.md#когда-изменения-уходят-в-базу) |
| **zpg: Preview SQL** | есть незаписанные правки | открывает SQL, который выполнится |
| **zpg: Open row** | курсор на строке данных | открывает строку вертикально → [Просмотр строки](07-relations.md#просмотр-строки) |
| **zpg: Insert row** | таблица редактируема | вставляет заготовку новой строки под курсором |
| **zpg: Filter: col = '…'** / **<>** / **IS NULL** / **IS NOT NULL** | курсор на ячейке данных, нет правок | задаёт `where`; при заданном — **Also filter**, через `AND` → [Фильтр](05-table.md#фильтр-по-значению-ячейки) |
| **zpg: Clear filter (where=)** | задан `where`, нет правок | убирает фильтр |
| **zpg: Sort by \<колонка\> ↑ / ↓** | курсор на имени колонки, нет правок | сортирует, с первой страницы |
| **zpg: Next / Previous / First / Last page (2/37)** | нет правок | другая страница → [Листать](05-table.md#листать-страницы) |
| **zpg: Refresh** / **Refresh (discard changes)** | всегда | перечитывает страницу и структуру из базы, отбрасывая правки |
| **zpg: Apply changes manually (apply=manual)** / **on save (apply=save)** | всегда | переключает режим записи в шапке |
| **zpg: Show DDL** | всегда | DDL таблицы |
| **zpg: Back up \<таблица\> (pg_dump)** | всегда | бэкап таблицы через `pg_dump` |
| **zpg: Export page as CSV / JSON / INSERT statements** | всегда | экспорт загруженной страницы → [Экспорт](10-export.md) |
| **zpg: Export all rows matching where= as CSV** | всегда | экспорт всех строк через `COPY` |
| **zpg: Rows of \<таблица\> referencing this (\<колонки\>)** | курсор на строке данных | строки другой таблицы, ссылающиеся на эту; по одному на внешний ключ, в конце меню → [Связи](07-relations.md#кто-ссылается-на-строку) |

### Просмотр строки (`.pgr`)

| Действие | Когда | Что делает |
|---|---|---|
| **zpg: Apply changes (1 update)** | есть незаписанная правка | записывает строку |
| **zpg: Refresh row (discard changes)** | всегда | перечитывает строку из базы |
| **zpg: Rows of … referencing this (…)** | всегда | как в таблице |

### `.sql`

| Действие | Когда | Что делает |
|---|---|---|
| **zpg: Run statement on \<подключение\>** | курсор на запросе | выполняет его (то же, что ▶) |
| **zpg: Run selection on \<подключение\>** | выделен текст | выполняет выделенные запросы одной транзакцией |
| **zpg: Explain statement on \<подключение\>** | курсор на `SELECT`/`INSERT`/`UPDATE`/`DELETE`/`WITH`/`VALUES`/`MERGE` | план без выполнения (то же, что кнопка Explain) |
| **zpg: Explain analyze statement on \<подключение\> (runs it, then rolls back)** | то же | выполняет с замером и откатывает → [EXPLAIN](08-sql.md#explain) |

### Результат запроса (`.pgres`)

| Действие | Когда | Что делает |
|---|---|---|
| **zpg: Run again** | всегда | перезапускает запрос |
| **zpg: Edit rows in table** | все колонки из одной таблицы, есть её ключ | страница таблицы, отфильтрованная запросом → [Результаты](08-sql.md#править-строки-результата) |
| **zpg: Export result as CSV / JSON** | всегда | экспорт результата |
| **zpg: Cancel the query of pid N** | есть колонка `pid`, курсор на строке | `pg_cancel_backend` → [Администрирование](09-admin.md#прервать-запрос-или-сессию) |
| **zpg: Terminate backend pid N…** | то же | `pg_terminate_backend`, после подтверждения |

### Во время выполнения запроса или pg_dump

| Действие | Где | Что делает |
|---|---|---|
| **zpg: Cancel the statement running on \<подключение\>** | в любом файле, пока идёт запрос | отменяет его → [Отмена](08-sql.md#отмена-долгого-запроса) |
| **zpg: Cancel pg_dump of \<таблица\>** | в любом файле, пока идёт бэкап | останавливает `pg_dump`, удаляет недописанный файл |

## Команды language server

Их вызывают code actions и code lens; вручную не нужны, но видны в логах.

| Команда | Действие |
|---|---|
| `zpg.open`, `zpg.openRow` | Open \<таблица\>, Open row |
| `zpg.refresh`, `zpg.page`, `zpg.sort`, `zpg.filter` | Refresh, страницы, сортировка, фильтр |
| `zpg.apply`, `zpg.previewSql` | Apply changes, Preview SQL |
| `zpg.referencing` | Rows of … referencing this |
| `zpg.ddl`, `zpg.drop`, `zpg.backup` | Show DDL, Drop, Back up |
| `zpg.run`, `zpg.rerun`, `zpg.explain`, `zpg.editResult` | запуск, Run again, Explain, Edit rows in table |
| `zpg.export` | все виды экспорта |
| `zpg.activity`, `zpg.signal`, `zpg.cancel` | активность, Cancel/Terminate backend, отмена своего запроса |
| `zpg.openConfig` | Open settings file |

## Поля шапки таблицы

| Поле | Меняется | Описание |
|---|---|---|
| `conn` | нет | подключение |
| `table` | нет | `схема.таблица` |
| `pk` | нет | колонки первичного ключа; `""` — ключа нет (только чтение) |
| `page` | да | номер страницы, с 1 |
| `limit` | да | строк на странице, 1–10 000 |
| `total` | нет | сколько строк под `where`; `~N` — оценка |
| `width` | да | ширина обрезки значений, `0` — без обрезки |
| `apply` | да | `manual` или `save` |
| `where` | да | SQL-условие |
| `order` | да | SQL-сортировка; без поля — по ключу |
| `columns` | да | видимые колонки через запятую |

Подробно — [Страница таблицы](05-table.md#шапка).

## Специальные значения в ячейках

| Пишете | Означает |
|---|---|
| `NULL` | SQL NULL |
| `DEFAULT` | значение по умолчанию |
| `+` в ключе | новая строка, ключ по умолчанию |
| пусто | пустая строка `''` |
| `\NULL`, `\DEFAULT`, `\+` | текст `NULL`, `DEFAULT`, `+` |
| `\|`, `\\`, `\n`, `\t`, `\r`, `\s` | `\|`, `\`, перевод строки, табуляция, CR, пробел по краю |

## Файлы в `.zpg`

```
.zpg/
├── .gitignore                         # «*»: папка не попадает в git
├── catalog.pgdb                       # каталог
├── history.sql                        # история запусков из .sql
└── local/                             # по папке на подключение
    ├── zpg_demo.orders.pgt            # страница таблицы
    ├── zpg_demo.orders.preview.sql    # последний Preview SQL
    ├── zpg_demo.orders.ddl.sql        # последний Show DDL
    ├── drop-zpg_demo.orders.sql       # последний Drop…
    ├── activity.pgres                 # активность сервера
    ├── backups/
    │   └── zpg_demo.orders-20261018-021333.sql   # бэкапы pg_dump (.sql, .dump, .tar)
    ├── exports/
    │   └── zpg_demo.orders.csv        # экспорт (.csv, .json, .sql)
    ├── results/
    │   ├── report.pgres               # результат последнего запуска из report.sql
    │   └── report.plan.txt            # последний Explain из report.sql
    ├── zpg_demo.orders.rows/
    │   ├── 1.pgr                      # просмотр строки с ключом 1
    │   └── .state/
    └── .state/
        └── zpg_demo.orders.pgt.json   # что было загружено из базы — с ним сравниваются правки
```

- `.zpg` создаётся рядом с ближайшей папкой `.zed` или в корне проекта.
- `.state/*.json` нужен, чтобы понять, что именно вы изменили. Не удаляйте его, пока в файле есть незаписанные правки.
- Всю папку `.zpg` можно удалить, когда нет незаписанных правок: она пересоздастся при следующем открытии.
- Значения таблиц, экспорты и история лежат на диске в открытом виде. Учитывайте это для чувствительных данных.

## Ошибки и что делать

### В таблице и просмотре строки

| Сообщение | Причина | Что делать |
|---|---|---|
| `duplicate key: this row appears twice` | одна строка (по ключу) встречается дважды | удалите копию, поменяйте ключ или поставьте `+` |
| `value is cut to fit the line…` | правка обрезанного значения | откройте строку (F12 на ключе), увеличьте `width` или сократите `columns` |
| `row has N cells, the page shows M columns` | стёрт или добавлен лишний `\|` | восстановите разметку строки |
| `a new row needs …: add to columns=` | у новой строки не хватает обязательной скрытой колонки | добавьте её в `columns=` |
| `` `columns`: no such column … `` | опечатка в `columns=` | исправьте имя (подскажет автодополнение) |
| `rows are N characters and Zed wraps lines over 512…` | таблица не влезает даже после сужения колонок | оставьте нужные колонки через `columns=` |
| `column row must stay …` | изменена строка с именами колонок | верните её как была |
| `expected field …`, `missing field …` | в просмотре строки удалено или переставлено поле | верните поле на место |
| `key fields can't be changed here` | в просмотре строки изменён ключ | ключ меняется только в таблице |
| `read-only: …` | нет первичного ключа, view или подключение `read_only` | такую таблицу можно только смотреть |
| `row was changed or deleted since it was loaded` | строку изменили в базе после загрузки | **Refresh**, затем правьте заново |
| `not saved: <ошибка Postgres>` | база отклонила запрос (NOT NULL, FK, UNIQUE, CHECK, тип) | исправьте значение в указанной строке |
| `no saved state for this file` | файл открыт не из каталога или удалён `.state` | **Refresh** или откройте заново из каталога |
| `apply or discard changes first` | смена страницы/сортировки/фильтра при незаписанных правках | **Apply changes** или **Refresh (discard changes)** |
| `no more rows` | следующая страница пустая | вы на последней странице |

### Подключения

| Сообщение | Причина | Что делать |
|---|---|---|
| `! …` в каталоге | не удалось подключиться | проверьте строку подключения и переменные окружения |
| `…/config.json: …` | ошибка в файле настроек | исправьте место из сообщения; до этого действуют прежние настройки |
| ``no connection `x` in …`` | в файле подключение, которого нет в настройках | добавьте его в `~/.config/zpg/config.json` |
| `environment variable X is not set` | в URL есть `${X}`, а переменной нет | задайте переменную и перезапустите Zed |
| `error communicating with the server`, `terminating connection…` при записи или запуске SQL | соединение оборвалось во время выполнения | нажмите ещё раз — zpg подключится заново; чтение повторяется само, см. [Обрыв соединения](02-connections.md#обрыв-соединения) |
| `invalid peer certificate: UnknownIssuer` | `verify-ca`/`verify-full`, а сертификат подписан не доверенным CA | укажите CA в `sslrootcert`, см. [TLS](02-connections.md#tls-и-проверка-сертификата); или `sslmode=require` — без проверки |
| `invalid peer certificate: certificate not valid for name …` | `verify-full`, а сертификат выдан на другое имя | подключайтесь по имени из сертификата (`host=имя hostaddr=адрес`) или `sslmode=verify-ca` |
| `sslrootcert …: No such file or directory` | нет файла из `sslrootcert` | проверьте путь |
| `ssh to …: Host key verification failed` | сервера нет в `known_hosts` | один раз зайдите на сервер `ssh` из терминала |
| `ssh to …: Permission denied (publickey…)` | ключ не подошёл или не в agent | `ssh-add`, проверьте `~/.ssh/config`; вход по паролю не поддерживается |
| `ssh to …: no tunnel after 20 s` | ssh завис на подключении | проверьте доступность сервера и `ProxyJump` |
| `can't run pg_dump: No such file or directory` | `pg_dump` не установлен или не в `PATH` | поставьте `postgresql-client` или укажите путь в `"pg_dump"` |
| `pg_dump failed: … server version mismatch` | `pg_dump` старше сервера не умеет | укажите в `"pg_dump"` версию не ниже серверной |
| `pg_dump's directory format can't be written to one file` | в `pg_dump_args` стоит `-Fd` | используйте `-Fc` или обычный формат |

### SQL

| Сообщение | Причина | Что делать |
|---|---|---|
| подчёркнутая ошибка после сохранения | [проверка запросов](08-sql.md#проверка-запросов) нашла ошибку | исправьте и сохраните |
| ошибка после ▶, `(rolled back)` | Postgres отклонил запрос, всё откачено | исправьте подчёркнутое место и запустите снова |
| жёлтое подчёркивание, вопрос «Run on …?» | [опасный запрос](08-sql.md#опасные-запросы) | проверьте запрос, **Run** или **Cancel** |
| `the file changed since this ▶ was drawn…` | файл правился, zpg не нашёл запрос | нажмите ▶ ещё раз |
| `zpg: cancelled (rolled back)` | запрос отменён | — |
| `canceling statement due to statement timeout` | сработал `statement_timeout_ms` | увеличьте настройку или ускорьте запрос |
| `read-only: query result…` в `.pgres` | результат правится не здесь | **Edit rows in table** |
| `the query has a string spanning lines…` | для «Edit rows in table» запрос должен уместиться в одну строку шапки | уберите перевод строки из строкового литерала |
| нет кнопок ▶ над запросами | не установлено расширение SQL, выключены code lens или нет подключений | [Установка](01-install.md) |

Сообщения сервера всплывают в правом нижнем углу Zed. Подробный лог: `ctrl-shift-p` → **dev: open language server logs** → `zpg`.

## Ограничения

- Это текст, а не грид: таблицы прокручиваются по горизонтали. Строки длиннее 512 символов Zed переносит в любом случае, см. [Широкие таблицы](05-table.md#широкие-таблицы).
- Сервер обрабатывает одно действие за раз: пока идёт запрос, hover и автодополнение ждут. Запрос можно [отменить](08-sql.md#отмена-долгого-запроса), а длительность ограничивает `statement_timeout_ms`.
- Запросы с параметрами `$1` выполнить нельзя (их некуда подставить); проверка запросов их пропускает. Команды `psql` (`\d`, `\copy`) не поддерживаются.
- Страница загружается в буфер целиком. Для больших таблиц используйте `where` и `limit`, а не листайте тысячи страниц.
- Сертификат сервера проверяется только при `sslmode=verify-ca` / `verify-full`; клиентские сертификаты (`sslcert`, `sslkey`) не поддерживаются; SSH — только по ключу.
- В режиме `apply=save` каждое сохранение сразу пишется в базу. С автосохранением Zed (`"autosave"`) используйте только `manual`.
- DDL из **Show DDL** не включает владельцев, права и параметры хранения — для полного дампа используйте `pg_dump`.
