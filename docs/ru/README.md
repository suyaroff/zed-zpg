# zpg: руководство

zpg — расширение Zed для работы с PostgreSQL. Таблица открывается как обычный текстовый файл: правите ячейки как текст, сохраняете и применяете изменения, а zpg сам превращает их в `UPDATE`, `INSERT` и `DELETE` и выполняет одной транзакцией.

Кроме таблиц, zpg умеет запускать запросы из `.sql`-файлов с автодополнением, проверкой и EXPLAIN, показывать структуру таблиц, экспортировать данные и следить за активностью сервера. Всё это — через привычные действия Zed: **F12** (go to definition), **hover**, **автодополнение** и **`ctrl-.`** (code actions). Своих панелей у расширений Zed нет, поэтому zpg работает через текстовые буферы и language server.

```
# zpg v1 conn=local table=zpg_demo.orders pk=id page=1 limit=100 total=9 width=40 apply=manual
| id | customer_id | status    | created_at                    | total  | comment             |
|----|-------------|-----------|-------------------------------|--------|---------------------|
| 1  | 1           | paid      | 2026-09-28 01:40:44.321115+05 | 64.90  | NULL                |
| 2  | 1           | shipped   | 2026-10-06 01:40:44.321115+05 | 289.00 | Подарочная упаковка |
| 3  | 2           | new       | 2026-10-17 23:40:44.321115+05 | 39.40  | NULL                |
```

## Примеры

Все примеры руководства построены на демо-схеме `zpg_demo` (покупатели, товары, заказы). Создайте её, чтобы повторять их у себя:

- [`docs/examples/demo.sql`](../examples/demo.sql) — создаёт схему `zpg_demo` с данными; запуск повторно возвращает данные к исходным, `DROP SCHEMA zpg_demo CASCADE` удаляет всё.
- [`docs/examples/tour.sql`](../examples/tour.sql) — пошаговый обход возможностей `.sql`-файлов.

Демо-схема описана в [быстром старте](03-quickstart.md#демо-схема).
